# Роли и ответственность

| Направление | Задача | Возможная ветка |
|---|---|---|
| Юридическое | Статус патента, лицензия, правовые барьеры | `legal/patent-status` |
| Технологическое | Реализуемость, эксперименты, схемы | `tech/prototype-validation` |
| Продуктовое | ЦА, интервью, аналоги, ценность | `product/customer-discovery` |
| Редактор / координатор | Согласованность, источники, принятие PR | `docs/review-notes` |

На каждый документ назначается ответственный. Выводы, влияющие на решения, проходят проверку минимум ещё одним участником.
