# Lean Canvas

## Почему выбрали его

[ВНЕШНИЙ ИСТОЧНИК] Создатель Lean Canvas называет его адаптацией Business Model Canvas для стартапов ([LEANSTACK](https://leanstack.com/), проверено 21.10.2026).

[ГИПОТЕЗА] Сейчас важнее проверить, есть ли у конкретного заказчика повторяющаяся проблема, чем подробно расписывать партнёров и ресурсы уже работающей компании. Поэтому для одной возможной бизнес-модели берём Lean Canvas. После интервью и технического демонстратора к модели можно вернуться и уточнить её.

Вариант для проверки: носимый пульт для сотрудника, который управляет несколькими интерактивными экспонатами через установленные рядом считыватели. Это **предположение команды**, не заявленный патентом рынок и не результат интервью.

| Блок Lean Canvas | Наш черновик |
|---|---|
| Проблема | [ГИПОТЕЗА] Сотруднику неудобно переключать режимы экспозиции через разные панели, пульты и приложения. Сейчас он может пользоваться обычной кнопкой, телефоном или штатной панелью — их надо сравнить с кольцом. |
| Сегмент клиентов | [ГИПОТЕЗА] Первый пользователь — сотрудник интерактивного музея или выставки; заказчик — организация, которая эксплуатирует экспозицию. Ранний контакт — площадка с несколькими управляемыми стендами. |
| Уникальное предложение | [ГИПОТЕЗА] Несколько локальных команд с одного носимого предмета без поиска нужного пульта. Обещание «без зарядки» допустимо только после испытаний. |
| Решение | [ГИПОТЕЗА] Пульт с ограниченным числом понятных команд и совместимый считыватель у стенда. Интерфейс проверяем сначала крупным макетом. |
| Каналы | [ГИПОТЕЗА] Прямой пилот с площадкой и интегратором экспозиции; серийный канал пока не определён. |
| Доходы | [ГИПОТЕЗА] Оплата комплекта и настройки на площадке; размер чека и готовность платить неизвестны. |
| Издержки | [ГИПОТЕЗА] Прототипы, считыватели, интеграция, изготовление корпусов, испытания и сопровождение. Сметы пока нет. |
| Ключевые метрики | Число частых действий, время команды, ошибки, ложные срабатывания, доля пользователей, предпочёвших устройство обычной кнопке, готовность площадки к пилоту. Базовые значения пока неизвестны. |
| Труднокопируемое преимущество | [НЕИЗВЕСТНО] Пока не найдено. Патент сам по себе не доказывает ни превосходство продукта, ни право команды им распоряжаться. |

## Что опирается на документ

- [ПАТЕНТ] Описаны кольцо с двумя галетными переключателями, кнопкой, движковым переключателем и антенной (с. 6 [PDF](../06_Источники/Patent_RU2834675_C1.pdf)).
- [ПАТЕНТ] Внешнее устройство должно распознавать команды кольца; оно же создаёт поле для питания (с. 6–7 PDF).
- [НЕИЗВЕСТНО] Нет подтверждённых данных о себестоимости, спросе, цене, прототипе и совместимых считывателях.
